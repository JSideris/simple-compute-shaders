# Simple Compute Shaders - Example Gallery

This is a centralized gallery of examples for the `simple-compute-shaders` library.

## To Run

From the root of the project:
```bash
npm run examples
```

Or from this directory:
```bash
npm install
npm run dev
```

## Features

- **Hello Triangle**: Basic rendering.
- **Game of Life**: Compute shaders with buffer swapping.
- **Bitonic Sort**: Large dataset sorting on GPU.
- **Audio Processor**: Real-time microphone audio processing.
- **RPS-9**: 9-way Rock Paper Scissors simulation.
